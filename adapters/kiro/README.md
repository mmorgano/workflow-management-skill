# Kiro Adapter

The root `SKILL.md` is the Kiro-compatible adapter retained for backward
compatibility. Install the repository as `skill-workflow-management` under
Kiro's skills directory, then run `setup-skills.sh` or, on Windows,
`setup-skills.ps1`.

Its workflow rules are aligned with the platform-independent contract in
`CORE.md`, the portable defaults in `conventions.md`, and the mode-specific
files under `references/`.
